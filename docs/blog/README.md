# PenThePet Blog Posts

This directory contains blog posts about the development of PenThePet.

## Contents

### building-penthepet.md
**Main Article** - A concise account of building PenThePet with AI-assisted development, covering what worked, what didn't, and lessons learned.

- **Length**: ~1,600 words (~7 minute read)
- **Style**: Professional technical writing, accessible to a general audience
- **Tone**: Balanced and honest — treats AI as a useful tool, not a silver bullet

**Topics Covered**:
- The motivation and technical setup (GitHub Pages, vanilla JS)
- What AI handled well: scaffolding, tests, standard algorithms
- What AI struggled with: puzzle generation, optimization, architecture
- The solver saga: 8 PRs across two languages to get it right
- Why periodic human refactoring was essential
- Practical observations for anyone considering AI-assisted development

### Supporting files
- `outline.md` - Planning document used to structure the original long-form draft
- `pr-analysis.json` - Structured categorization of all 48 pull requests

## Key Themes

1. AI is a useful development tool, not a replacement for engineering judgment
2. Well-defined tasks (boilerplate, tests) go smoothly; judgment-heavy tasks (algorithms, architecture) don't
3. The hardest parts of the project were the parts where a human had to step in
4. It was a fun experiment worth doing again — with realistic expectations
