# docs/summaries/

This folder contains historical summaries of major changes, bug fixes, and refactoring sessions. They are kept for reference and are not the source of truth for current design decisions.

## What belongs here

- One-off summary documents created after significant changes (e.g., `FIXES_SUMMARY_2026-02-06.md`)
- Do **not** put active documentation here — use the parent `docs/` folder for that
