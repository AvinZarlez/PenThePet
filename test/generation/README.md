# test/generation/

This folder contains Jest tests for the offline map generation pipeline.

## What belongs here

- Tests for `MapGenerator`, `MapValidator`, `scripts/generate-map.js`, and `scripts/lib/mapUtils.js`
- Any new test files for generation-related modules in `js/` or `scripts/`

## Documentation

For the full testing guide, including file descriptions and how to run these tests, see **[../../docs/TESTING.md](../../docs/TESTING.md)**.
