# assets/

This folder contains all SVG art assets used as tile backgrounds and overlays in the game grid.

## What belongs here

- SVG files for each tile type (`grass.svg`, `water.svg`, `wall.svg`, `home.svg`, `penned.svg`, `paw.svg`)
- Any replacement or additional tile artwork in SVG (or PNG/JPEG) format

## Documentation

For asset inventory, design guidelines, sizes, and replacement instructions, see **[../docs/ART_ASSETS.md](../docs/ART_ASSETS.md)**.
